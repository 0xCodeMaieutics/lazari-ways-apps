## Employers onboarding process

1. [E]: Receive login data from `Lazariways`
2. [E]: Logs in using login data at `https://employer.lazariways.eu/login`

## Sharing Applications Process

1. [FW]: View vacancies on `https://vacancies.lazariways.eu/<agent-id>`
2. [FW]: Click on 'Apply for vacancy' and go to `https://employee.lazariways.eu?agentName=''&vacancyId=''`
3. [FW]: Signs up in the app.
4. [FW]: Fills up the basic information.
5. [FW]: Submits an application.
6. [A]: Receives the application.
7. [A]: Books automatically an interview if necessary.
8. [A]: After a successful interview, application gets activated or shared to an employer.
9. [A]: If candidates doesn't meet the criteria, they are left in the system with 'REJECTED' status with a 'NOTE' written why he got rejected.
10. [E]: Checks out "Employer Dashboard" `https://employer.lazariways.eu`, evaluates applications.
11. [E]: Clicks on "Interested" and will be navigated to Whatsapp link with a specific `applicationID` if they like the profile.
12. [E]: Clicks on "Not interested" if they don't like the application. The application disappears from "Employer Dashboard".
